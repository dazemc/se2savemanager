## Run from source

1. Clone the repo:

    ```bash
    git clone https://github.com/dazemc/se2savemanager.git
    cd se2savemanager
    ```

2. Get dependencies:

    ```bash
    flutter pub get
    ```

3. Run the app:

    ```bash
    dart run build_runner build
    flutter run
    ```
